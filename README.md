# TikTok Live Chat Overlay

A minimalist read-only TikTok LIVE chat overlay for OBS and streaming.
Transparent, always-on-top and lightweight - it sits quietly on top of
your scene without blocking clicks.

---

## Features

- Realtime chat with viewer comments
- Gift feed with combo tracking
- Activity toasts for follow, share, repost, and join
- Top viewers and top likes popups
- Live stats: viewers, likes, and duration
- Auto-reconnect on network drops
- Settings drawer with persistent preferences
- Colored bubbles per event type

---

## Setup

1. Launch the app
2. Enter `@username` or a TikTok LIVE link
3. Click **Connect**
